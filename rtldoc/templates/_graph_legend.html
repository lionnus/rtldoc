{# The legend of the block diagram. The module page and the overview share it. #}

input · output · interface — the wide green line is a stream or a bus, and the arrow gives the direction of the data · control — the dashed amber line shows which module controls what · flag / status · no direction. A hexagon is a port that goes in two directions. A dashed inner box is a generate block. The dashed white node is the logic of the module itself: the processes that drive or read a control net. The clock, reset, clear and test-mode nets are not in the graph; the chips below the diagram give them.
